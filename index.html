LAFIYAR UWA LIMITED

Privacy Policy

Your privacy matters to us. This policy explains how Lafiyar Uwa collects, uses, stores, and protects information when you use our application and related services.

Effective Date: September 26, 2026
Last Updated: September 26, 2026

Lafiyar Uwa Limited ("Lafiyar Uwa", "we", "our", or "us") respects your privacy and is committed to protecting the information you provide when using the Lafiyar Uwa mobile application and related services.

Lafiyar Uwa is a digital maternal-health support platform designed to help women and families access pregnancy information, pregnancy tracking, reminders, emergency support, health education, voice guidance, and healthcare-related information.

This Privacy Policy explains what information the Lafiyar Uwa application may collect, how that information is used, how it is stored, and the choices available to users.

1. Information We Collect

Depending on how you use Lafiyar Uwa, the application may collect and process the following information.

1.1 Account and Profile Information

When you create or use a Lafiyar Uwa account, we may collect:

  • Name
  • Email address
  • Account authentication information
  • User account identifier (UID)
  • Profile information that you provide

Lafiyar Uwa uses Firebase Authentication to manage user authentication and account access.

Each authenticated user is associated with a unique user identifier (UID), which is used to associate the user's records with their account.

1.2 Pregnancy and Maternal-Health Information

To provide pregnancy-tracking and maternal-health support features, the application may process information that you enter or generate through your use of the application, including:

  • Pregnancy information
  • Pregnancy dates and gestational information
  • Expected delivery information
  • Delivery-related records
  • Maternal-health information entered by the user
  • Reminder-related information
  • Other information necessary for pregnancy tracking and related features

Because some of this information relates to pregnancy and health, we treat it as sensitive information and use it only for the purposes described in this Privacy Policy.

1.3 Reminder and Notification Information

Lafiyar Uwa allows users to receive reminders related to pregnancy and maternal-health activities.

The application may store information necessary to create and manage these reminders, including reminder dates, times, titles, and related reminder content.

Notifications currently use local device notifications. Lafiyar Uwa does not currently use Firebase Cloud Messaging for these notifications.

1.4 SOS and Emergency Support Information

The application includes SOS and emergency-support functionality.

Information associated with the use or configuration of this functionality may include information necessary to provide the emergency-support feature, including relevant location information where the feature uses location data.

1.5 Location Information

Lafiyar Uwa may process location information to support features such as location-aware emergency support and helping users identify nearby healthcare facilities.

The type of location information processed depends on the feature being used and the information available to the application.

We do not use location information for advertising purposes.

1.6 Voice Guidance

Lafiyar Uwa provides Hausa and English voice guidance.

The voice-guidance feature uses text-to-speech technology to convert application text into spoken audio.

Important: Lafiyar Uwa does not record, store, or upload microphone recordings through the voice-guidance feature.

2. How We Use Information

We use information collected through Lafiyar Uwa to operate and provide the application's features, including:

  • Creating and managing user accounts
  • Authenticating users
  • Maintaining user profiles
  • Providing pregnancy tracking
  • Calculating and displaying pregnancy-related information
  • Maintaining delivery-related records
  • Providing maternal-health education
  • Providing pregnancy-related guidance
  • Creating and managing reminders
  • Providing SOS and emergency-support functionality
  • Supporting location-related features
  • Helping users access nearby healthcare facilities
  • Providing Hausa and English voice guidance
  • Synchronizing relevant information between the application and backend services
  • Improving the reliability and functionality of the application

We do not currently use the information described in this policy for targeted advertising.

3. How We Store Information

Lafiyar Uwa uses Firebase Authentication and Cloud Firestore as part of its backend infrastructure.

Account and application records are associated with the user's Firebase Authentication UID so that information can be associated with the correct account.

The application also supports an offline-first approach, which means certain application information may be stored locally on the user's device to allow relevant functionality when an internet connection is unavailable.

When connectivity is available, relevant information can be synchronized with the application's backend.

4. Data Security

We take reasonable measures to protect information processed through Lafiyar Uwa against unauthorized access, alteration, disclosure, or destruction.

Data transmitted between the application and applicable backend services is protected using encryption in transit.

However, no electronic storage or transmission system can be guaranteed to be completely secure. Users should also protect their account credentials and device from unauthorized access.

5. Services We Do Not Currently Implement

As of the effective date of this Privacy Policy, Lafiyar Uwa does not currently implement the following Firebase services/features:

  • Firebase Analytics
  • Firebase Crashlytics
  • Firebase Cloud Messaging
  • Firebase Storage

Lafiyar Uwa also does not use its voice-guidance feature to record or store microphone audio.

If these technologies or substantially different data-processing practices are introduced in the future, this Privacy Policy may be updated accordingly.

6. Sharing of Information

We do not sell your personal information.

We do not share your personal information with third parties for targeted advertising.

Lafiyar Uwa uses technology infrastructure and service providers necessary to operate the application, including Firebase services used for authentication and backend data processing.

Information may also be disclosed where necessary to comply with applicable law, legal processes, or valid governmental requests.

7. Health Information

Lafiyar Uwa may process pregnancy and maternal-health information that users provide through the application.

This information is used to provide the application's pregnancy-tracking, education, reminder, emergency-support, and related features.

Medical disclaimer: Lafiyar Uwa is a digital health-support and educational tool. Information provided through the application does not replace professional medical diagnosis, treatment, or advice.

If you have a medical concern, pregnancy complication, or emergency, seek assistance from a qualified healthcare professional or appropriate emergency service.

8. Data Retention

We retain account and application information for as long as reasonably necessary to provide the Lafiyar Uwa service and maintain the user's account and associated functionality.

If a user requests account deletion, we will process the request in accordance with our account-deletion procedures.

Certain information may need to be retained where required or permitted by applicable law, for security purposes, to resolve disputes, or to protect our legal rights.

9. Account Deletion

Users may request deletion of their Lafiyar Uwa account and associated personal information.

To request account deletion, contact us using:

Email: support@lafiyaruwa.com

Please include the email address associated with your Lafiyar Uwa account and clearly state that you are requesting account deletion.

You can also visit our dedicated account deletion page:

https://lafiyaruwa.com/delete-account

Deleting the application from your device does not necessarily delete your Lafiyar Uwa account or associated server-side information. Users should submit an account-deletion request if they want their account deleted.

Some information may be retained where required or permitted by applicable law, security requirements, dispute resolution, or legitimate legal purposes.

10. Children's Privacy

Lafiyar Uwa is designed primarily for adults, including pregnant women and women planning pregnancy.

The service is not intentionally designed to collect personal information from children.

If we become aware that personal information has been collected from a child in circumstances where such collection is not permitted, we will take reasonable steps to address the situation.

11. Third-Party Services

Lafiyar Uwa relies on third-party infrastructure to provide certain technical functionality.

Firebase

Lafiyar Uwa uses Firebase services, including Firebase Authentication and Cloud Firestore, for account authentication and backend data management.

Firebase may process information according to its own privacy practices and applicable agreements.

Lafiyar Uwa does not currently use Firebase Analytics, Crashlytics, Cloud Messaging, or Firebase Storage as part of the application's implemented functionality.

12. Offline Data

Lafiyar Uwa is designed with offline-first functionality.

Some information may therefore be temporarily stored locally on the user's device so that supported features can continue to function when internet connectivity is unavailable.

The availability and duration of locally stored information may depend on the particular feature and the user's device.

Users should protect their devices with appropriate security measures such as a device password, PIN, biometric authentication, or other available security controls.

13. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in:

  • The Lafiyar Uwa application
  • Our data-processing practices
  • Applicable laws or regulations
  • Security practices
  • New features or services

When we make changes, we will update the Last Updated date at the beginning of this policy.

We encourage users to review this Privacy Policy periodically.

In summary, Lafiyar Uwa:

  • Uses Firebase Authentication for user accounts and authentication.
  • Associates user records with unique Firebase user IDs (UIDs).
  • Processes profile, pregnancy, delivery, reminder, SOS, and relevant location information to provide application functionality.
  • Supports offline-first functionality and local data synchronization.
  • Uses local device notifications for supported reminders.
  • Provides Hausa and English voice guidance using text-to-speech.
  • Does not record microphone audio through its voice-guidance feature.
  • Does not currently implement Firebase Analytics or Crashlytics.
  • Does not currently implement Firebase Cloud Messaging.
  • Does not currently implement Firebase Storage.
  • Does not sell personal information.
  • Does not use personal information for targeted advertising.
  • Provides a process for requesting account deletion.
